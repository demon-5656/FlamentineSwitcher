# Ограничения Wayland

FlamentineSwitcher не перехватывает ввод и не пытается автоматически переписывать текст в фоне. Это сознательное ограничение: Wayland защищает ввод между приложениями.

Поддерживается только явное действие **Конвертировать выделение** через shortcut Plasma. Для него нужны `ydotoold`, Klipper и служба раскладок Plasma; `flamentine-switcher --check-wayland` проверяет их до работы.
